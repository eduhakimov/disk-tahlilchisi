# Disk Analyzer

## Scanning
1. In the **Location** field, pick a drive, or click the folder icon to choose a folder.
2. Click **Scan**. You can **Stop** at any time; the results will then be partial.
3. You can also start a scan from the cards on the Drives tab.

Junctions and symbolic links are not followed, so no file is counted twice.
The number of inaccessible folders is shown in the status line. To see system folders completely,
run the app as administrator.

## Tabs
- **Map**: each rectangle is a folder or file, sized by how much space it takes. Colour shows the file type.
  Click a folder to open it. Go back with the arrow or by clicking a name in the path bar.
  Right-click to show an item in Explorer or move it to the Recycle Bin.
- **Folders**: tree view. Click a column header to sort; double-click to open a folder on the map.
- **Largest files**: the 100 largest files.
- **File types**: space by category and by extension.
- **Old files**: large files that have not been opened or modified for the chosen period.
- **Cleanup**: browser, Unity and Adobe caches, Temp folders and other temporary files. Click **Measure** first,
  then check the locations you want and click **Move checked to Recycle Bin**.

## Safety
Nothing is deleted permanently: everything goes to the Recycle Bin, after a confirmation.
Drive roots, Windows, Program Files and the user folders themselves cannot be deleted.
To empty the Recycle Bin, click **Open Recycle Bin**.

## Reports
The **Report** menu saves the results as HTML or CSV.
